# Projects - Fall 2025

Member projects that the club is running or supporting this semester: hackathon teams, competition prep, a website rebuild, a workshop series.

## One folder per project

Folder name in kebab-case, for example `website-rebuild`. Each folder has a `README.md` with:

| Section | Content |
|---|---|
| Goal | one sentence, plus how you will know it is done |
| Owner | role, or a name with consent on file |
| Status | `proposed`, `active`, `paused`, `done`, `dropped` |
| Links | the project's own repo, drive folder, or event folder |
| Log | dated one-liners as things happen |

## Code lives elsewhere

This repo holds the club's records, not project code. Put code in its own repository and link it. Keep the project folder here to a README and small planning notes.

## At semester close

Every project folder has a final status. Anything still `active` goes into [handoff.md](../handoff.md) as an open thread with the role that picks it up.

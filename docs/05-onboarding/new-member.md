# New member checklist

Welcome to ACM @ RCC. This is everything you need in your first two weeks. You do not need a GitHub account to be a member; you only need one if you want to help maintain this repo.

## Day one

- [ ] Join the Discord: <https://discord.gg/fM2HbsJyBG>. This is where announcements, questions, and last-minute room changes happen. If the link says `[TBD]`, ask an officer at a meeting.
- [ ] Follow the Instagram: <https://www.instagram.com/rcc.acm/>.
- [ ] Come to a weekly meeting: Thursdays, 12:50 to 1:50 PM in BLCIS A-210. No sign-up needed. What a meeting looks like is in [weekly-meeting.md](../03-playbooks/weekly-meeting.md).
- [ ] Read the [mission](../00-charter/mission.md) (two minutes) and the [code of conduct](../../CODE_OF_CONDUCT.md) (five minutes).

## First two weeks

- [ ] Read [membership.md](../00-charter/membership.md) for what "active member" means and whether ACM (Association for Computing Machinery) membership is required for anything you want to do.
- [ ] Look at this semester's calendar under `semesters/` (the current folder is the highest-numbered one; start at [semesters/README.md](../../semesters/README.md)). Pick one event and put it in your own calendar.
- [ ] Introduce yourself in Discord: name, what you are studying, what you want to build or learn.
- [ ] If you want to run something, skim [event-checklist.md](../02-operations/event-checklist.md) so you know what it takes, then pitch it in Discord or at a meeting. There are also `Event proposal` and `Workshop proposal` issue templates on GitHub if you prefer writing it up.

## Things members often ask

| Question | Answer |
| --- | --- |
| Do I have to pay? | Club membership: see [membership.md](../00-charter/membership.md). RCC's Student Services fee is a college matter, not a club one. |
| Do I have to attend every week? | No. Show up when you can. Some events (trips, competitions) have their own commitment rules in their playbook. |
| Where is the club's money from? | Mostly ASRCC, RCC's student government. How that works is in [asrcc-funding.md](../02-operations/asrcc-funding.md). |
| Can I get reimbursed for something I bought for the club? | Only if it was approved first. Read [reimbursements.md](../02-operations/reimbursements.md) before you spend. |
| Will my name end up on GitHub? | Not unless you become an officer and agree to it. See [privacy-and-public-repo-policy.md](../01-governance/privacy-and-public-repo-policy.md). |
| How do I become an officer? | [elections.md](../00-charter/elections.md) and [officer-roles.md](../00-charter/officer-roles.md). |
| I found a typo or a broken link. | Open a PR or tell an officer. [CONTRIBUTING.md](../../CONTRIBUTING.md) explains the PR rules. |

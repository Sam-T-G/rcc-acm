| File | Read it when |

| [asrcc-funding.md](./asrcc-funding.md) | February through May. The annual ASRCC funding request and hearing. |
| [reimbursements.md](./reimbursements.md) | Before anyone spends money. Requisitions, receipts, the trust account. |
| [room-booking.md](./room-booking.md) | Before any meeting or event that needs a room. 25Live goes through the advisor. |

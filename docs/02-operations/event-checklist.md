# Event checklist

One page to run any club event at RCC, from a workshop to a trip. Create the event folder first with `scripts/new-event.sh`, which drops in the plan, run sheet, and retro from `templates/`. Then work down this list.

Playbooks for specific event types are in [docs/03-playbooks/](../03-playbooks/README.md).

## T-6 weeks: decide

- [ ] Event folder created: `semesters/<YYYY-term>/events/<YYYY-MM-DD>-<slug>/`
- [ ] [event-plan.md](../../templates/event-plan.md) filled: goal, audience, headcount, date options, owner
- [ ] Two candidate dates checked against the semester `calendar.md` (holidays, finals, Club Rush, ICC events)
- [ ] Budget line identified in `budget.md`, or a decision that this event costs nothing
- [ ] Advisor confirmed available on the date (RCC requires the advisor at club events)
- [ ] Go/no-go logged in [decision-log.md](../01-governance/decision-log.md)

## T-5 weeks: book

- [ ] Room request emailed to the advisor with every detail ([room-booking.md](./room-booking.md))
- [ ] Speaker or facilitator confirmed in writing, with what they need (AV, whiteboard, laptop)
- [ ] Line item drafted if ASRCC money is involved ([funding-line-item.md](../../templates/funding-line-item.md))
- [ ] Requisition started for anything the college can pay directly ([reimbursements.md](./reimbursements.md))

## T-4 weeks: paperwork

- [ ] Advisor has submitted the 25Live request (2-week college minimum; we aim for 4)
- [ ] Student Activities Event Form submitted with the printed 25Live confirmation
- [ ] Food Authorization filed if food is served
- [ ] College Safety and Police contacted if the event runs outside normal hours or has outside guests: [TBD lead time]
- [ ] For trips: RCC travel paperwork [TBD], driver and vehicle plan, lodging requisition

## T-3 weeks: announce

- [ ] Second 25Live email (the approval) received. Do not announce before this.
- [ ] Event published on the parent org platform if the club uses one (ACM (Association for Computing Machinery))
- [ ] Announcement drafted from [announcement.md](../../templates/announcement.md), with "Funded by ASRCC" if it applies
- [ ] Posted to Discord and Instagram per [communications.md](./communications.md)
- [ ] Faculty asked to announce in class (send them the two-line version)
- [ ] Flyer follows [brand.md](../04-brand/brand.md); ASRCC acknowledged on it when funded

## T-2 weeks: build

- [ ] [event-run-sheet.md](../../templates/event-run-sheet.md) drafted: minute-by-minute, who does what
- [ ] Materials list done (slides, handouts, starter code, sign-in method)
- [ ] Supplies ordered by requisition or bought with pre-approval
- [ ] Reminder post scheduled

## T-1 week: confirm

- [ ] Reminder posted in every channel
- [ ] Speaker reconfirmed, parking or directions sent
- [ ] Headcount estimate updated from RSVPs; room and food adjusted
- [ ] Attendance method ready ([attendance-tracking.md](./attendance-tracking.md))
- [ ] Roles assigned: door, AV, timekeeper, photographer (consent forms if faces will be posted)
- [ ] Advisor reminded of date, time, room

## Day before

- [ ] Walk the room if you can: power, projector, chairs, whiteboard markers
- [ ] Print the run sheet and the 25Live confirmation
- [ ] Final "tomorrow" post in Discord

## Day of

- [ ] Arrive 30 minutes early; set up per the run sheet
- [ ] Sign-in open before the first person arrives
- [ ] Acknowledge ASRCC out loud at the start if funded
- [ ] Photos only of people who agreed
- [ ] Take attendance count at the peak, write it on the run sheet
- [ ] Leave the room as you found it; take trash with you

## T+1 day

- [ ] Attendance count entered where [attendance-tracking.md](./attendance-tracking.md) says
- [ ] Thank-you to speaker and advisor
- [ ] Receipts to the treasurer, amounts into `budget.md`
- [ ] Recap post with one photo (consented) and a link to materials

## T+1 week: close

- [ ] [event-retro.md](../../templates/event-retro.md) filled by the owner, reviewed by one other officer
- [ ] Reimbursements submitted
- [ ] Anything that surprised you turned into a fix: a line in a playbook, a template change (with a decision record), or a [TBD] replaced in these docs
- [ ] PR opened with the retro, budget update, and any doc fixes

## Minimum viable event

A one-hour on-campus workshop in the regular room during the regular slot (Thursdays, 12:50 to 1:50 PM, BLCIS A-210) needs only: the plan, an announcement, sign-in, and the retro. Everything else on this list is for events that need a different room, money, food, or travel.

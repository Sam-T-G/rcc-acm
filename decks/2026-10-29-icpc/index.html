Start here

  1. Get a way to run C++. Any compiler works. In a terminal: g++ -std=c++17 a.cpp -o a, then ./a < in.txt runs your program with the input from in.txt.
  2. Read step 1 first. Every ICPC problem gives you input as plain text, in one of a few shapes. Each shape below has a short program you can copy and run.
  3. Open problem 1. The link opens the official problem set PDF from the contest. The page number is in the link.
  4. Copy its starter code. The starter already reads the input. You fill in the middle.
  5. Test on the sample. Copy the sample input from the PDF into in.txt and run your program. Your output has to match the sample output exactly, spaces and capital letters included.
  6. Go to the next problem. They're in order by how many teams solved each one at the real contest. Each has a hint, the common mistake, and an answer if you're stuck.

Step 1: input and output

These are the input shapes ICPC problems use most. Start with the first few and come back to the rest when a problem needs them.

The basics. Your program reads from standard input (cin) and writes to standard output (cout). Don't open files, and don't print prompts like "Enter a number:". Anything extra you print counts as wrong output. (DOMjudge team manual: "Solutions have to read all input from 'standard in' and write all output to 'standard out'.")

Test locally the way the judge does: g++ -std=c++17 -Wall a.cpp -o a && ./a < a.in

0. Starter template (type this first)

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

void solve() {
    ll a, b;
    cin >> a >> b;
    cout << a + b << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1;
    cin >> T;               // delete this line if there's only one case
    while (T--) solve();
}

In: 2 / 1 2 / 3000000000 1 Out: 3 / 3000000001

  • <bits/stdc++.h> pulls in the whole standard library in one line. It's a GCC file, so it works with g++ on Linux and Windows. Apple's default compiler on a Mac doesn't have it, so on a Mac list the headers you need instead (<iostream>, <vector>, <string>, <algorithm>).
  • Mistake: forgetting to delete cin >> T; on a problem with one case. Your program reads the first number as T.

1. Count first, then the values

You see: "The first line contains an integer n. The next line contains n integers."

int n;
cin >> n;
vector<int> a(n);
for (int i = 0; i < n; i++) cin >> a[i];

In: 5 / 3 1 4 1 5 Out (sum): 14

  • cin >> skips spaces and newlines, so it doesn't matter if the n values are on one line or many.
  • Mistake: vector<int> a; then a[i] = .... The vector is empty, so that writes past the end. Use vector<int> a(n) or push_back.

3. Big numbers: use long long

You see: values up to 10^9 or bigger, or anything that gets added or multiplied together.

int stops at 2,147,483,647 (about 2.1 × 10^9). long long goes up to about 9.2 × 10^18.

long long a, b;
cin >> a >> b;
cout << a + b << "\n" << a * b << "\n";
int x = 100000, y = 100000;
long long good = 1LL * x * y;   // x * y alone overflows as int first
cout << good << "\n";

In: 2000000000 3000000000 Out: 5000000000 / 6000000000000000000 / 10000000000

  • Mistake: long long p = x * y; with int x, y. The multiply happens in int and overflows before it's stored. Write 1LL * x * y.
  • Mistake: reading 3000000000 into an int. cin fails, and every read after that fails too.
  • Put sums of many values and any product in long long.
Full program you can run
09_long_long.cpp
#include <iostream>
using namespace std;

int main() {
    // int max is 2,147,483,647 (about 2.1e9). long long goes to about 9.2e18.
    long long a, b;            // read into long long, not int
    cin >> a >> b;
    cout << a + b << "\n";
    cout << a * b << "\n";

    int x = 100000, y = 100000;
    // long long bad = x * y;     // int * int overflows BEFORE it's stored
    long long good = 1LL * x * y; // 1LL makes the math happen in long long
    cout << good << "\n";
}

10000000000

4. Fast I/O and "\n" vs endl

You see: n up to 10^5 or 10^6, or a time limit you're barely missing.

ios::sync_with_stdio(false);
cin.tie(nullptr);
...
cout << x << "\n";      // not endl
  • endl prints a newline and also flushes the output every time. On a million lines that's slow. "\n" just prints the newline.
  • Mistake: after sync_with_stdio(false), mixing cin/cout with scanf/printf. The output can come out in the wrong order. Pick one.
Full program you can run
10_fast_io.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);   // after this, don't mix cin/cout with scanf/printf
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n);
    for (auto& x : a) cin >> x;
    for (int x : a) cout << 2 * x << "\n";   // "\n", not endl: endl flushes every line
}

Input

3
1 2 3

Output

2
4
6

5. Read until end of file (no count given)

You see: "Input consists of several lines" or "process until end of input," with no n.

long long x, sum = 0;
int count = 0;
while (cin >> x) { sum += x; count++; }
cout << count << " " << sum << "\n";

In: 4 8 / 15 / 16 23 42 Out: 6 108

  • cin >> x returns false when there's nothing left, so the loop stops on its own.
  • Mistake: while (!cin.eof()). When the file ends with a newline (almost always), the loop runs one extra time and the failed read leaves the last value in x, so it gets counted twice (on the sample: 7 150). Put the read inside the while.
  • To type end of file by hand in the terminal: Ctrl+D (Mac/Linux). Easier to use ./a < a.in.
Full program you can run
03_until_eof.cpp
#include <iostream>
using namespace std;

int main() {
    long long x, sum = 0;
    int count = 0;
    while (cin >> x) {         // stops when there's nothing left to read
        sum += x;
        count++;
    }
    cout << count << " " << sum << "\n";
}

4 8
15
16 23 42

Output

6 108

7. Output formatting: decimals and spaces

You see: "Print the answer rounded to 2 decimal places" or "print the values on one line separated by spaces."

cout << fixed << setprecision(2) << (double)sum / n << "\n";   // needs <iomanip>
for (int i = 0; i < n; i++) {
    if (i > 0) cout << " ";
    cout << a[i];
}
cout << "\n";

In: 3 / 1 2 2 Out: 1.67 / 1 2 2

  • fixed << setprecision(2) means exactly 2 digits after the decimal point. Without fixed, setprecision(2) means 2 digits total (1.7).
  • Mistake: sum / n with two ints. That's integer division (5 / 3 is 1). Cast one side to double first.
  • Whitespace: by default the judge's checker treats any run of spaces and newlines as the same, and decimals must match exactly unless the problem gives an allowed error (problem package format spec; the DOMjudge manual says "some extra whitespace may be ignored," depending on the problem). Don't count on it. Match the sample output's format exactly.
  • If the problem says "absolute or relative error of at most 10^-6," print more digits than that (setprecision(9)).
Full program you can run
11_formatting.cpp
#include <iomanip>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    long long sum = 0;
    for (auto& x : a) { cin >> x; sum += x; }

    // decimals: fixed + setprecision(k) = exactly k digits after the point
    cout << fixed << setprecision(2) << (double)sum / n << "\n";

    // a vector on one line, one space between values, none at the end
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << a[i];
    }
    cout << "\n";
}

3
1 2 2

Output

1.67
1 2 2

8. Grids: R C, then R lines of characters

You see: "The first line has R and C. The next R lines each have C characters" (. open, # wall, S start).

int R, C;
cin >> R >> C;
vector<string> g(R);
for (int r = 0; r < R; r++) cin >> g[r];
// g[r][c] is row r, column c

In: 3 4 / #..# / .S.. / ##.# Out: 5 walls, start at 1 1

  • cin >> g[r] reads one row because rows have no spaces. If a row can contain spaces, use getline (section 10).
  • Mistake: mixing up g[r][c] and g[c][r]. Row first, then column. Also check bounds (0 <= r < R, 0 <= c < C) before looking at a neighbor.
Full program you can run
07_grid.cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int R, C;
    cin >> R >> C;
    vector<string> g(R);
    for (int r = 0; r < R; r++) cin >> g[r];   // works when rows have no spaces

    int walls = 0, sr = -1, sc = -1;
    for (int r = 0; r < R; r++)
        for (int c = 0; c < C; c++) {          // g[r][c] = row r, column c
            if (g[r][c] == '#') walls++;
            if (g[r][c] == 'S') { sr = r; sc = c; }
        }
    cout << walls << " walls, start at " << sr << " " << sc << "\n";
}

Input

3 4
#..#
.S..
##.#

Output

5 walls, start at 1 1

9. A record per line, then sort

You see: "Each of the next n lines contains a name and a score." Output: "sorted by score, highest first; break ties by name."

struct Player { string name; int score; };
vector<Player> p(n);
for (auto& x : p) cin >> x.name >> x.score;
sort(p.begin(), p.end(), [](const Player& a, const Player& b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
});

In: 4 / bob 70 / amy 90 / cal 70 / dee 85 Out: amy 90 / dee 85 / bob 70 / cal 70

  • Mistake: forgetting the tie-break. Two players with 70 can come out in either order, and the judge expects one.
  • Mistake: using >= or <= in the compare. It has to be strict (> or <) or sort can crash.
  • Quick version: vector<pair<int,string>> sorts by the first field, then the second, with no compare function.
Full program you can run
08_structs.cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Player {
    string name;
    int score;
};

int main() {
    int n;
    cin >> n;
    vector<Player> p(n);
    for (auto& x : p) cin >> x.name >> x.score;

    // highest score first; ties go alphabetical by name
    sort(p.begin(), p.end(), [](const Player& a, const Player& b) {
        if (a.score != b.score) return a.score > b.score;
        return a.name < b.name;
    });
    for (auto& x : p) cout << x.name << " " << x.score << "\n";
}

dee 85

10. Whole lines with spaces: getline

You see: "Each line contains a full name" or a sentence, so the text has spaces in it.

int n;
cin >> n;
cin.ignore();              // throw away the '\n' left after n
for (int i = 0; i < n; i++) {
    string line;
    getline(cin, line);
    cout << "Hello, " << line << "!\n";
}

In: 2 / Ada Lovelace / Grace Brewster Hopper Out: Hello, Ada Lovelace! / Hello, Grace Brewster Hopper!

  • cin >> s stops at the first space. getline(cin, s) reads up to the end of the line.
  • The bug: cin >> n leaves the newline after n sitting in the input. The first getline reads that, so you get an empty first line and lose the last real one. Without cin.ignore() the output above is Hello, ! / Hello, Ada Lovelace!.
  • Fix 1: cin.ignore(); once after the last cin >>. Fix 2: getline(cin >> ws, line); skips all spaces and newlines before the line starts. Fix 2 also skips blank lines, so don't use it when a blank line means something.
Full program you can run
05_getline.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    cin.ignore();              // throw away the '\n' left after n
    for (int i = 0; i < n; i++) {
        string line;
        getline(cin, line);    // whole line, spaces included
        cout << "Hello, " << line << "!\n";
    }
    // Same fix in one call: getline(cin >> ws, line);
    // ws skips all whitespace (spaces, newlines) before the line starts.
}

Input

2
Ada Lovelace
Grace Brewster Hopper

Output

Hello, Ada Lovelace!
Hello, Grace Brewster Hopper!

11. Unknown count per line: stringstream

You see: "Each line contains some integers" with no count, and you need an answer per line.

string line;
while (getline(cin, line)) {
    stringstream ss(line);          // needs <sstream>
    int x, sum = 0, count = 0;
    while (ss >> x) { sum += x; count++; }
    cout << "count " << count << ", sum " << sum << "\n";
}

In: 1 2 3 / 10 / 5 5 5 5 5 Out: count 3, sum 6 / count 1, sum 10 / count 5, sum 25

  • stringstream ss(line) lets you use >> on one line only, the same way you use it on cin. Works for words too: string w; while (ss >> w).
  • Mistake: reading with cin >> here. cin doesn't stop at the end of a line, so you can't tell where one line ends and the next begins.

Before you submit: run every sample. Check the output format against the sample character by character. Remove debug prints. Check long long anywhere numbers get big.

Full program you can run
06_stringstream.cpp
#include <iostream>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string line;
    while (getline(cin, line)) {       // one line at a time
        stringstream ss(line);
        int x, sum = 0, count = 0;
        while (ss >> x) {              // pull numbers until the line runs out
            sum += x;
            count++;
        }
        cout << "count " << count << ", sum " << sum << "\n";
    }
}

Input

1 2 3
10
5 5 5 5 5

Output

count 3, sum 6
count 1, sum 10
count 5, sum 25

    Balance of Power

    SoCal 2023-24 Regional, problem 7 · 81 of 84 teams solved it

    Count how many legislators each of 3 parties has. If one party has more than the other two put together, print that it dominates. Otherwise print Power Balanced.

    Starter code
    Reads the input for you. Fill in the middle.
    #include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {

        // your code here: count each party
    }

    cout << "TODO\n";

    Hint

    Keep 3 counters. Party 1 dominates when its count is bigger than the total minus its count.

    Common mistake

    Show an answer

    Try the hint first.

    One answer. It passes the official sample.
    #include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count[4] = {0, 0, 0, 0};   // count[1], count[2], count[3]
    for (int i = 0; i < n; i++) {
        int party;
        cin >> party;
        count[party]++;
    }
    string names[4] = {"", "Future One", "Two-gether", "Triple Harmony"};
    int total = count[1] + count[2] + count[3];
    for (int p = 1; p <= 3; p++) {
        if (count[p] > total - count[p]) {   // more than the other two combined
            cout << names[p] << " Dominates\n";
            return 0;
        }
    }
    cout << "Power Balanced\n";
    return 0;
}

    #include <iostream>

int main() {

    cin >> a >> b >> c;
    long long lo = min({a, b, c});

    long long allBars = 0;

    SoCal 2024-25 Regional, problem 11 · 81 of 88 teams solved it

    Open the problem (official PDF, page 23)

    For each test case you get a name and a short form. Print YES if every letter in the short form shows up somewhere in the name, NO if not.

    Input: test cases T, 2 words each. Uses: bool array of 26 letters.

    Starter code
    Reads the input for you. Fill in the middle.

#include <string>

    int t;
    cin >> t;
    while (t--) {

    Hint

    Mark the letters of the name in a bool array of 26. Then check each letter of the short form.

    Common mistake

    Checking letter counts or letter order. The problem says repeats and order don't matter. Print YES and NO in capitals.

    Show an answer

    Try the hint first.

    One answer. It passes the official sample.
    #include <iostream>
#include <string>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        string a, b;
        cin >> a >> b;
        bool inA[26] = {false};
        for (char ch : a) inA[ch - 'a'] = true;
        bool ok = true;

    Try the hint first.

    #include <iostream>
#include <string>
#include <cstdio>
using namespace std;

int main() {
    string amount;
    while (cin >> amount) {                     // amounts until end of file
        string digits = "";
        for (char c : amount)
            if (c != '.') digits += c;          // "1.24" -> "124"

        if (last == 3 || last == 4) cents += 5 - last;
        if (last == 6 || last == 7) cents -= last - 5;
        if (last == 8 || last == 9) cents += 10 - last;

    Reads the input for you. Fill in the middle.

#include <string>
#include <cstdlib>
using namespace std;

int main() {
    string trip;
    while (cin >> trip) {   // keep reading trips until the input runs out
        // your code here: track the direction and position
        cout << "TODO\n";
    }

    Hint

    Keep x, y, and a direction 0 to 3. R adds 1, L adds 3, both mod 4. Each D moves one block and costs $1. The shortest trip costs abs(x) + abs(y).

    Common mistake

    Counting L and R as cost. Only D moves the taxi.

    Show an answer

    Try the hint first.

    One answer. It passes the official sample.
    #include <iostream>
#include <string>
#include <cstdlib>
using namespace std;

int main() {
    string trip;
    while (cin >> trip) {                  // one trip per line until end of file
        int dx[4] = {0, 1, 0, -1};         // north, east, south, west
        int dy[4] = {1, 0, -1, 0};
        int dir = 0, x = 0, y = 0, paid = 0;

        if (paid == shortest) cout << "fair fare\n";
        else cout << "overpaid by " << paid - shortest << "\n";

}

    Digital Speedometer

    SoCal 2020-21 Regional, problem 5 · 44 of 70 teams solved it

    Open the problem (official PDF, pages 10-11)

    Turn each speed reading into a whole number for the display. In the middle band between two thresholds, the display keeps showing what it showed coming from below or above.

    Input: 2 values, then until end of file. Uses: double, looking back through history.

    Starter code
    Reads the input for you. Fill in the middle.
    #include <iostream>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    double tf, tr;
    cin >> tf >> tr;
    vector<double> seen;
    double s;
    while (cin >> s) {   // keep reading speeds until the input runs out
        // your code here
        cout << "TODO\n";
        seen.push_back(s);
    }
    return 0;
}
    Hint

    Keep every earlier speed in a vector. For a speed in the middle band, look back for the last speed outside that band and compare it to the rising threshold.

    Common mistake

    Forgetting the rule that any speed above 0 and below 1 shows as 1.

    Show an answer

    Try the hint first.

    One answer. It passes the official sample.
    #include <iostream>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    double tf, tr;
    cin >> tf >> tr;
    vector<double> seen;
    double s;
    while (cin >> s) {                        // speeds until end of file
        int shown;
        int i = (int)floor(s + 1e-9);
        if (s == 0) shown = 0;
        else if (s < 1) shown = 1;            // moving, so never show 0
        else if (s < i + tf) shown = i;
        else if (s > i + tr) shown = i + 1;
        else {
            // in the middle band: look back for the last speed outside it
            shown = i;
            for (int k = (int)seen.size() - 1; k >= 0; k--) {
                double v = seen[k];
                if (v < i + tf || v > i + tr) {
                    shown = (v < i + tr) ? i : i + 1;
                    break;
                }
            }
        }
        cout << shown << "\n";
        seen.push_back(s);
    }
    return 0;
}

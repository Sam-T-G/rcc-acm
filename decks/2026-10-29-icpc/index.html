Step 1The 4 input shapes you need first

An input shape is the way a problem lays out its input. These 4 cover most easy problems. Read with cin and print with cout. Don't print prompts like "Enter a number" or anything extra, because the judge (the program that grades your code) marks it wrong.

Optional: a template to start any problem

the code

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

void solve() {
    ll a, b;
    cin >> a >> b;
    cout << a + b << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1;
    cin >> T;               // delete this line if there's only one case
    while (T--) solve();
}

In: 2 / 1 2 / 3000000000 1 Out: 3 / 3000000001

  • <bits/stdc++.h> includes the whole C++ standard library in one line. It comes with the GCC compiler, so it works with g++ on Linux and Windows. Apple's default compiler on a Mac doesn't have it, so on a Mac list the headers you need instead (<iostream>, <vector>, <string>, <algorithm>).
Common mistake

forgetting to delete cin >> T; on a problem with one case. Your program reads the first number as T.

    Count first, then the values

    You see: "The first line contains an integer n. The next line contains n integers."

    the code

    int n;
cin >> n;
vector<int> a(n);
for (int i = 0; i < n; i++) cin >> a[i];

    In: 5 / 3 1 4 1 5 Out (sum): 14

    • cin >> skips spaces and newlines, so it doesn't matter if the n values are on one line or many.

  3. 3

    Read until end of file (no count given)

    You see: "Input consists of several lines" or "process until end of input," with no n.

    the code

    long long x, sum = 0;
int count = 0;
while (cin >> x) { sum += x; count++; }
cout << count << " " << sum << "\n";

    In: 4 8 / 15 / 16 23 42 Out: 6 108

    • End of file means the input has run out. cin >> x returns false then, so the loop stops on its own.
    • To type end of file by hand in the terminal: Ctrl+D on Mac or Linux, Ctrl+Z then Enter on Windows. It's easier to run ./a < in.txt.
    Common mistake

    while (!cin.eof()). When the file ends with a newline (almost always), the loop runs one extra time and the failed read leaves the last value in x, so it gets counted twice (on the sample: 7 150). Put the read inside the while.

    Full program you can run

    03_until_eof.cpp

    #include <iostream>
using namespace std;

int main() {
    long long x, sum = 0;
    int count = 0;
    while (cin >> x) {         // stops when there's nothing left to read
        sum += x;
        count++;
    }
    cout << count << " " << sum << "\n";
}

    Input

    4 8
15
16 23 42

    Output

    6 108

  4. 4

    Whole lines with spaces: getline

    You see: "Each line contains a full name" or a sentence, so the text has spaces in it.

    the code

    int n;
cin >> n;
cin.ignore();              // throw away the '\n' left after n
for (int i = 0; i < n; i++) {
    string line;
    getline(cin, line);
    cout << "Hello, " << line << "!\n";
}

    In: 2 / Ada Lovelace / Grace Brewster Hopper Out: Hello, Ada Lovelace! / Hello, Grace Brewster Hopper!

    • cin >> s stops at the first space. getline(cin, s) reads up to the end of the line.
    • The bug: cin >> n leaves the newline after n sitting in the input. The first getline reads that, so you get an empty first line and lose the last real one. Without cin.ignore() the output above is Hello, ! / Hello, Ada Lovelace!.
    • Fix 1: cin.ignore(); once after the last cin >>. Fix 2: getline(cin >> ws, line); skips all spaces and newlines before the line starts. Fix 2 also skips blank lines, so don't use it when a blank line means something. If in.txt was saved on Windows or has a space after the number, Fix 1 can still leave an empty line, so Fix 2 is the safer default.
    Full program you can run

    05_getline.cpp

    #include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    cin.ignore();              // throw away the '\n' left after n
    for (int i = 0; i < n; i++) {
        string line;
        getline(cin, line);    // whole line, spaces included
        cout << "Hello, " << line << "!\n";
    }
    // Same fix in one call: getline(cin >> ws, line);
    // ws skips all whitespace (spaces, newlines) before the line starts.
}

    Input

    2
Ada Lovelace
Grace Brewster Hopper

    Output

    Hello, Ada Lovelace!
Hello, Grace Brewster Hopper!

    Balance of Power

    SoCal 2023-24 Regional, problem 7 · 81 of 84 teams solved it

    Open the problem (PDF, page 17)

    Count how many legislators each of 3 parties has. If one party has more than the other two put together, print that it dominates. Otherwise print Power Balanced.

    Input: count, then numbers. Uses: counters, exact output text.

    Starter code

    This code already reads the input. You write the code that finds the answer and prints it.

    problem 1 starter

    #include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        int party;
        cin >> party;
        // your code here: count each party
    }
    // your code here: print "Power Balanced" or "<Party> Dominates"
    cout << "TODO\n";
    return 0;
}
    Hint

    Keep 3 counters. Party 1 dominates when its count is bigger than the total minus its count.

    Common mistake

    Typos in the output. The names are Future One, Two-gether, Triple Harmony, then a space and Dominates. Also, a tie with the other two combined is still balanced, so use >, not >=.

    Show an answer

    Try the hint first. This answer passes the official sample.

    problem 1 answer

    #include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count[4] = {0, 0, 0, 0};   // count[1], count[2], count[3]
    for (int i = 0; i < n; i++) {
        int party;
        cin >> party;
        count[party]++;
    }
    string names[4] = {"", "Future One", "Two-gether", "Triple Harmony"};
    int total = count[1] + count[2] + count[3];
    for (int p = 1; p <= 3; p++) {
        if (count[p] > total - count[p]) {   // more than the other two combined
            cout << names[p] << " Dominates\n";
            return 0;
        }
    }
    cout << "Power Balanced\n";
    return 0;
}

#include <algorithm>
using namespace std;

int main() {
    long long a, b, c;
    cin >> a >> b >> c;
    long long lo = min({a, b, c});
    long long hi = max({a, b, c});
    long long allBars = 0;
    for (long long len = lo; len <= hi; len++) allBars += len;  // every bar from lo to hi
    cout << allBars - a - b - c << "\n";                       // minus the 3 you own
    return 0;
}

    problem 3 starter

    #include <iostream>
#include <string>
using namespace std;

int main() {
    int t;
    cin >> t;

        string a, b;
        cin >> a >> b;

    Hint

    Mark the letters of the name in a bool array of 26. Then check each letter of the short form.

    Common mistake

    Checking letter counts or letter order. The problem says repeats and order don't matter. Print YES and NO in capitals.

    Show an answer

    Try the hint first. This answer passes the official sample.

    #include <iostream>
#include <string>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        string a, b;
        cin >> a >> b;

        for (char ch : a) inA[ch - 'a'] = true;
        bool ok = true;
        for (char ch : b)
            if (!inA[ch - 'a']) ok = false;
        cout << (ok ? "YES" : "NO") << "\n";
    }
    return 0;
}

    Ultimate Binary Watch

    SoCal 2021-22 Regional, problem 1 · 43 of 48 teams solved it

    Open the problem (PDF, pages 3-4)

    For each 4-digit time, print the time and then 4 rows that show each digit in binary, with * for a 1 and . for a 0.

    Input: until end of file. Uses: binary digits, printing a grid exactly.

    Starter code

    This code already reads the input. You write the code that finds the answer and prints it.

    problem 4 starter

    #include <iostream>
#include <string>
using namespace std;

int main() {
    string t;
    while (cin >> t) {   // keep reading times until the input runs out
        // your code here: print the time, then the 4 rows of the watch face
        cout << "TODO\n";
    }
    return 0;
}
    Hint

    Read each time as a string so 0830 keeps its 0. Build each row as 9 spaces and fill columns 1, 3, 7, and 9 (indexes 0, 2, 6, 8). The top row is the 8s place.

    Common mistake

    Getting the spaces wrong. There are exactly 3 spaces between the hours and the minutes, and nothing after the last column. Reading the time as an int also loses the leading 0.

    Show an answer

    Try the hint first. This answer passes the official sample.

    problem 4 answer

    #include <iostream>
#include <string>
using namespace std;

int main() {
    string t;
    while (cin >> t) {                       // times until end of file
        cout << t << "\n";
        for (int bit = 3; bit >= 0; bit--) { // top row is the 8s bit
            string row = "         ";        // 9 columns of spaces
            int col[4] = {0, 2, 6, 8};       // columns 1, 3, 7, 9
            for (int d = 0; d < 4; d++) {
                int digit = t[d] - '0';
                row[col[d]] = ((digit >> bit) & 1) ? '*' : '.';
            }
            cout << row << "\n";
        }
    }
    return 0;
}

    GPA Computation

    SoCal 2025-26 Regional, problem 1 · 63 of 76 teams solved it

    Open the problem (PDF, page 3)

    Each class has a grade A to E and a tier 1 to 3. Average the grade points, then add a small bonus for each A, B, or C in a tier 1 or tier 2 class.

    Input: count, then short codes. Uses: subtracting chars, printing decimals.

    Starter code

    This code already reads the input. You write the code that finds the answer and prints it.

    problem 6 starter

    #include <iostream>
#include <iomanip>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        string g;
        cin >> g;   // g[0] is the letter, g[1] is the tier
        // your code here
    }
    cout << "TODO\n";
    return 0;
}
    Hint

    Read each code as a string. 'E' - g[0] gives the points. Add the bonuses after you divide, not before.

    Common mistake

    Dividing the bonus by n. Also, printing with plain cout gives only 6 digits; use fixed << setprecision(9).

    Show an answer

    Try the hint first. This answer passes the official sample and all 100 official judge tests (posted by the Pacific Northwest regional, which used the same problem).

    problem 6 answer

    #include <iostream>
#include <iomanip>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    double points = 0, bonus = 0;
    for (int i = 0; i < n; i++) {
        string g;
        cin >> g;                        // like "A1": letter, then tier
        char letter = g[0], tier = g[1];
        points += 'E' - letter;          // A=4, B=3, C=2, D=1, E=0
        if (letter <= 'C') {             // A, B, or C
            if (tier == '1') bonus += 0.05;
            if (tier == '2') bonus += 0.025;
        }
    }
    cout << fixed << setprecision(9) << points / n + bonus << "\n";
    return 0;
}

    Child's Play

    SoCal 2025-26 Regional, problem 7 · 60 of 76 teams solved it

    Open the problem (PDF, pages 17-18)

    Cubes are glued in a stack. Print the area you have to paint, which is the outside of the whole stack, bottom included.

    Input: count, then numbers. Uses: surface area, min of two sides.

    Starter code

    This code already reads the input. You write the code that finds the answer and prints it.

    problem 7 starter

    #include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        long long s;
        cin >> s;
        // your code here
    }
    cout << "TODO\n";
    return 0;
}
    Hint

    Each cube adds 6 * s * s. Each glued pair hides the smaller square on both cubes, so subtract 2 * m * m where m is the smaller side.

    Common mistake

    Subtracting the glued square only once. It's hidden on the top cube and on the bottom cube.

    Show an answer

    Try the hint first. This answer passes the official sample.

    problem 7 answer

    #include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long area = 0, prev = 0;
    for (int i = 0; i < n; i++) {
        long long s;
        cin >> s;
        area += 6 * s * s;                 // all 6 faces of this cube
        if (i > 0) {
            long long m = min(s, prev);    // the glued square
            area -= 2 * m * m;             // hidden on both cubes
        }
        prev = s;
    }
    cout << area << "\n";
    return 0;
}

    I Could Have Won

    SoCal 2022-23 Regional, problem 1 · 46 of 59 teams solved it

    Open the problem (PDF, page 3)

    Given who won each point in a table tennis match, find every k where Alice wins more games if a game ends when someone reaches k points.

    Input: one string. Uses: nested loops, replaying the match.

    Starter code

    This code already reads the input. You write the code that finds the answer and prints it.

    problem 8 starter

    #include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string pts;
    cin >> pts;   // one line of A's and B's
    // your code here: try each k from 1 to pts.size()
    cout << "TODO\n";
    return 0;
}
    Hint

    Try every k from 1 to the length. For each k, replay the points, and when someone reaches k, give them the game and reset both scores to 0.

    Common mistake

    Printing an empty second line when no k works. If the count is 0, print only the 0.

    Show an answer

    Try the hint first. This answer passes the official sample.

    problem 8 answer

    #include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string pts;
    cin >> pts;
    int n = pts.size();
    vector<int> good;
    for (int k = 1; k <= n; k++) {          // try every first-to-k rule
        int a = 0, b = 0, gamesA = 0, gamesB = 0;
        for (char c : pts) {
            if (c == 'A') a++; else b++;
            if (a == k) { gamesA++; a = 0; b = 0; }
            if (b == k) { gamesB++; a = 0; b = 0; }
        }
        if (gamesA > gamesB) good.push_back(k);
    }
    cout << good.size() << "\n";
    for (int i = 0; i < (int)good.size(); i++)
        cout << good[i] << (i + 1 < (int)good.size() ? " " : "\n");
    return 0;
}

    Penniless in America

    SoCal 2025-26 Regional, problem 9 · 57 of 76 teams solved it

    Open the problem (PDF, page 21)

    Round each price to the nearest 5 cents and print it with 2 digits after the decimal point.

    Input: until end of file. Uses: money as whole cents, printf("%02lld").

    Starter code

    This code already reads the input. You write the code that finds the answer and prints it.

    problem 9 starter

    #include <iostream>
#include <string>
#include <cstdio>
using namespace std;

int main() {
    string amount;
    while (cin >> amount) {   // keep reading until the input runs out
        // your code here: round to the nearest 5 cents
        cout << "TODO\n";
    }
    return 0;
}
    Hint

    Read each price as a string, drop the ., and turn it into whole cents. Round with the last digit, then print cents / 100 and cents % 100 with 2 digits.

    Common mistake

    Using double. 0.58 is stored as 0.5799999..., so (int)(x * 100) gives 57 and you print 0.55 instead of 0.60. Read the dollars and cents as whole numbers. Also, 1.20 needs the trailing 0.

    Show an answer

    Try the hint first. This answer passes the official sample.

    problem 9 answer

    #include <iostream>
#include <string>
#include <cstdio>
using namespace std;

int main() {
    string amount;
    while (cin >> amount) {                     // amounts until end of file
        string digits = "";
        for (char c : amount)
            if (c != '.') digits += c;          // "1.24" -> "124"
        long long cents = stoll(digits);
        int last = cents % 10;
        if (last == 1 || last == 2) cents -= last;
        if (last == 3 || last == 4) cents += 5 - last;
        if (last == 6 || last == 7) cents -= last - 5;
        if (last == 8 || last == 9) cents += 10 - last;
        printf("%lld.%02lld\n", cents / 100, cents % 100);
    }
    return 0;
}

    Hint

    Keep x, y, and a direction 0 to 3. R adds 1, L adds 3, then take % 4 so it stays 0 to 3. Each D moves one block and costs $1. The shortest trip costs abs(x) + abs(y).

    Common mistake

    Counting L and R as cost. Only D moves the taxi.

    Show an answer

    Try the hint first. This answer passes the official sample.

    problem 10 answer

    #include <iostream>
#include <string>
#include <cstdlib>
using namespace std;

int main() {
    string trip;
    while (cin >> trip) {                  // one trip per line until end of file
        int dx[4] = {0, 1, 0, -1};         // north, east, south, west
        int dy[4] = {1, 0, -1, 0};
        int dir = 0, x = 0, y = 0, paid = 0;
        for (char c : trip) {
            if (c == 'R') dir = (dir + 1) % 4;
            if (c == 'L') dir = (dir + 3) % 4;
            if (c == 'D') { x += dx[dir]; y += dy[dir]; paid++; }
        }
        int shortest = abs(x) + abs(y);
        if (paid == shortest) cout << "fair fare\n";
        else cout << "overpaid by " << paid - shortest << "\n";
    }
    return 0;
}

    Digital Speedometer

    SoCal 2020-21 Regional, problem 5 · 44 of 70 teams solved it

    Open the problem (PDF, pages 10-11)

    Turn each speed reading into a whole number for the display. In the middle band between the two thresholds, show the lower number if the last speed outside that band was below it, and the higher number if it was above.

    Input: 2 values, then until end of file. Uses: double, looking back at earlier speeds.

    Starter code

    This code already reads the input. You write the code that finds the answer and prints it.

    problem 12 starter

    #include <iostream>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    double tf, tr;
    cin >> tf >> tr;
    vector<double> seen;
    double s;
    while (cin >> s) {   // keep reading speeds until the input runs out
        // your code here
        cout << "TODO\n";
        seen.push_back(s);
    }
    return 0;
}
    Hint

    Keep every earlier speed in a vector. For a speed in the middle band, look back for the last speed outside that band and compare it to the rising threshold.

    Common mistake

    Forgetting the rule that any speed above 0 and below 1 shows as 1.

    Show an answer

    Try the hint first. This answer passes the official sample.

    problem 12 answer

    #include <iostream>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    double tf, tr;
    cin >> tf >> tr;
    vector<double> seen;
    double s;
    while (cin >> s) {                        // speeds until end of file
        int shown;
        int i = (int)floor(s + 1e-9);
        if (s == 0) shown = 0;
        else if (s < 1) shown = 1;            // moving, so never show 0
        else if (s < i + tf) shown = i;
        else if (s > i + tr) shown = i + 1;
        else {
            // in the middle band: look back for the last speed outside it
            shown = i;
            for (int k = (int)seen.size() - 1; k >= 0; k--) {
                double v = seen[k];
                if (v < i + tf || v > i + tr) {
                    shown = (v < i + tr) ? i : i + 1;
                    break;
                }
            }
        }
        cout << shown << "\n";
        seen.push_back(s);
    }
    return 0;
}

Big numbers: use long long

You see: values up to 10^9 or bigger, or anything that gets added or multiplied together.

int stops at 2,147,483,647 (about 2.1 × 10^9). long long goes up to about 9.2 × 10^18.

the code

long long a, b;
cin >> a >> b;
cout << a + b << "\n" << a * b << "\n";
int x = 100000, y = 100000;
long long good = 1LL * x * y;   // x * y alone overflows as int first
cout << good << "\n";

In: 2000000000 3000000000 Out: 5000000000 / 6000000000000000000 / 10000000000

  • Put sums of many values and any product in long long.
Common mistakes

long long p = x * y; with int x, y. The multiply happens in int, goes past the int limit, and wraps to a wrong number (that's called overflow) before it's stored. Write 1LL * x * y.

reading 3000000000 into an int. cin fails, and every read after that fails too.

Full program you can run

09_long_long.cpp

#include <iostream>
using namespace std;

int main() {
    // int max is 2,147,483,647 (about 2.1e9). long long goes to about 9.2e18.
    long long a, b;            // read into long long, not int
    cin >> a >> b;
    cout << a + b << "\n";
    cout << a * b << "\n";

    int x = 100000, y = 100000;
    // long long bad = x * y;     // int * int overflows BEFORE it's stored
    long long good = 1LL * x * y; // 1LL makes the math happen in long long
    cout << good << "\n";
}

Input

2000000000 3000000000

Output

5000000000
6000000000000000000
10000000000

Output formatting: decimals and spaces

You see: "Print the answer rounded to 2 decimal places" or "print the values on one line separated by spaces."

the code

cout << fixed << setprecision(2) << (double)sum / n << "\n";   // needs <iomanip>
for (int i = 0; i < n; i++) {
    if (i > 0) cout << " ";
    cout << a[i];
}
cout << "\n";

In: 3 / 1 2 2 Out: 1.67 / 1 2 2

  • fixed << setprecision(2) means exactly 2 digits after the decimal point. Without fixed, setprecision(2) means 2 digits total (1.7).
  • Spaces: by default the judge treats any run of spaces and newlines as the same, and decimals must match exactly unless the problem gives an allowed error (problem package format spec; the DOMjudge manual says "some extra whitespace may be ignored," depending on the problem). Don't depend on that. Match the sample output's format exactly.
  • If the problem says "absolute or relative error of at most 10^-6," print more digits than that (setprecision(9)).
Common mistake

sum / n with two ints. That's integer division (5 / 3 is 1). Cast one side to double first.

Full program you can run

11_formatting.cpp

#include <iomanip>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    long long sum = 0;
    for (auto& x : a) { cin >> x; sum += x; }

    // decimals: fixed + setprecision(k) = exactly k digits after the point
    cout << fixed << setprecision(2) << (double)sum / n << "\n";

    // a vector on one line, one space between values, none at the end
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << a[i];
    }
    cout << "\n";
}

Input

3
1 2 2

Output

1.67
1 2 2

Grids: R C, then R lines of characters

You see: "The first line has R and C. The next R lines each have C characters" (. open, # wall, S start).

the code

int R, C;
cin >> R >> C;
vector<string> g(R);
for (int r = 0; r < R; r++) cin >> g[r];
// g[r][c] is row r, column c

In: 3 4 / #..# / .S.. / ##.# Out: 5 walls, start at 1 1

  • cin >> g[r] reads one row because rows have no spaces. If a row can contain spaces, use getline (see "Whole lines with spaces").
Common mistake

mixing up g[r][c] and g[c][r]. Row first, then column. Also check bounds (0 <= r < R, 0 <= c < C) before looking at a neighbor.

Full program you can run

07_grid.cpp

#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int R, C;
    cin >> R >> C;
    vector<string> g(R);
    for (int r = 0; r < R; r++) cin >> g[r];   // works when rows have no spaces

    int walls = 0, sr = -1, sc = -1;
    for (int r = 0; r < R; r++)
        for (int c = 0; c < C; c++) {          // g[r][c] = row r, column c
            if (g[r][c] == '#') walls++;
            if (g[r][c] == 'S') { sr = r; sc = c; }
        }
    cout << walls << " walls, start at " << sr << " " << sc << "\n";
}

3 4

.S..
##.#

Output

5 walls, start at 1 1
Several values per line, then sort

You see: "Each of the next n lines contains a name and a score." Output: "sorted by score, highest first; break ties by name."

the code

struct Player { string name; int score; };
vector<Player> p(n);
for (auto& x : p) cin >> x.name >> x.score;
sort(p.begin(), p.end(), [](const Player& a, const Player& b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
});

In: 4 / bob 70 / amy 90 / cal 70 / dee 85 Out: amy 90 / dee 85 / bob 70 / cal 70

  • Quick version: vector<pair<int,string>> sorts by the first field, then the second, with no compare function.
Common mistakes

forgetting the tie rule. Two players with 70 can come out in either order, and the judge expects one.

using >= or <= in the compare function. It has to be strict (> or <) or sort can crash.

Full program you can run

08_structs.cpp

#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Player {
    string name;
    int score;
};

int main() {
    int n;
    cin >> n;
    vector<Player> p(n);
    for (auto& x : p) cin >> x.name >> x.score;

    // highest score first; ties go alphabetical by name
    sort(p.begin(), p.end(), [](const Player& a, const Player& b) {
        if (a.score != b.score) return a.score > b.score;
        return a.name < b.name;
    });
    for (auto& x : p) cout << x.name << " " << x.score << "\n";
}

Fast input and output, and "\n" vs endl

You see: n up to 10^5 or 10^6, or a time limit you're barely missing.

the code

ios::sync_with_stdio(false);
cin.tie(nullptr);
...
cout << x << "\n";      // not endl
  • endl prints a newline and also forces the output to be written out right away, every time. On a million lines that's slow. "\n" just prints the newline.
Common mistake

after sync_with_stdio(false), mixing cin/cout with scanf/printf. The output can come out in the wrong order. Pick one.

Full program you can run

10_fast_io.cpp

#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);   // after this, don't mix cin/cout with scanf/printf
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n);
    for (auto& x : a) cin >> x;
    for (int x : a) cout << 2 * x << "\n";   // "\n", not endl: endl flushes every line
}

Input

3
1 2 3

Output

2
4
6
Unknown count per line: stringstream

You see: "Each line contains some integers" with no count, and you need an answer per line.

the code

string line;
while (getline(cin, line)) {
    stringstream ss(line);          // needs <sstream>
    int x, sum = 0, count = 0;
    while (ss >> x) { sum += x; count++; }
    cout << "count " << count << ", sum " << sum << "\n";
}

In: 1 2 3 / 10 / 5 5 5 5 5 Out: count 3, sum 6 / count 1, sum 10 / count 5, sum 25

  • stringstream ss(line) lets you use >> on one line only, the same way you use it on cin. It works for words too: string w; while (ss >> w).
Common mistake

reading with cin >> here. cin doesn't stop at the end of a line, so you can't tell where one line ends and the next begins.

Full program you can run

06_stringstream.cpp

#include <iostream>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string line;
    while (getline(cin, line)) {       // one line at a time
        stringstream ss(line);
        int x, sum = 0, count = 0;
        while (ss >> x) {              // pull numbers until the line runs out
            sum += x;
            count++;
        }
        cout << "count " << count << ", sum " << sum << "\n";
    }
}

Input

1 2 3
10
5 5 5 5 5

Output

count 3, sum 6
count 1, sum 10
count 5, sum 25

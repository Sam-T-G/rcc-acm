Set upWire it

Parts

  • UNO board and its USB cable
  • Breadboard, with the power module taken off
  • Ultrasonic sensor (the blue board with two round eyes)
  • Servo with its arm on
  • 1 red LED and 1 green LED
  • 2 resistors marked 220 ohm (red, red, black, black, brown)
  • 12 jumper wires with a pin on both ends (2 more for the button challenge)
  • A notebook to play the car

Before you wire. Keep USB unplugged any time you change wires. Pull the power module off the breadboard, because the UNO powers the breadboard today. Swapping the sensor's Vcc and Gnd can damage it.

  1. Turn the breadboard so row 1 is on your right and the letters read the right way up. Line a is now the far edge.

  2. Put the UNO in front of the breadboard. e21 means line e, row 21.

  3. Wire the five groups. Some UNO pins have a ~ in front of the number, like ~9. Look for the number with the ~ beside it.

Power

These two jumpers bring power from the UNO to the bottom + and - rails.

  1. Trace it before USB. 5V goes to the bottom + rail (red line). Both GND jumpers go to - rails. e20 goes to the + rail and e23 to the - rail. Then plug in USB.

  2. Plug in USB and open Arduino IDE 2.

  3. Tools, Board: pick Arduino UNO. Tools, Port: pick the one that says Arduino UNO. On Windows the port is a COM number, like COM3.

On an UNO R4 WiFi board. Pick Arduino UNO R4 WiFi in Tools, Board (it needs the UNO R4 boards package). Use 1 kOhm resistors on both lights (brown, black, black, brown, brown), and skip the buzzer challenge. No sensor at your table? Wire the exit button (challenge 3) and use it as the car. Skip step 1. In each starter from step 2 on, change bool car = (cm > 0 && cm < CAR_CM); to bool car = (digitalRead(2) == LOW); and add pinMode(2, INPUT_PULLUP); in setup(). The R4's pins can't give as much power as the UNO's.

const int TRIG = 12;   // sensor Trig
const int ECHO = 11;   // sensor Echo

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  // 1. Send a 10 microsecond HIGH pulse on TRIG.
  //    (digitalWrite LOW, wait 2 us, HIGH, wait 10 us, LOW)

  // 2. Time the echo:  long us = pulseIn(ECHO, HIGH, 30000);

  // 3. Turn it into cm (58 microseconds per cm) and print it.

  delay(60);   // the sensor needs 60 ms between readings
}
    Hint 1

    The sensor sends a beep when the Trig pin goes HIGH for 10 microseconds (millionths of a second). delayMicroseconds(10) waits that long.

    Hint 2

    pulseIn(ECHO, HIGH, 30000) gives back how many microseconds the beep took to come back. Divide by 58 to get cm. It gives back 0 if nothing comes back within 30 ms (0.03 seconds).

const int TRIG = 12;   // sensor Trig
const int ECHO = 11;   // sensor Echo

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);                  // a 10 microsecond pulse starts a reading
  digitalWrite(TRIG, LOW);

  long us = pulseIn(ECHO, HIGH, 30000);   // wait at most 30 ms; 0 means no echo
  long cm = us / 58;                      // 58 microseconds per cm

  Serial.print("cm: ");
  Serial.println(cm);

  delay(60);
}

  1. 1

    Hold the arm until the car is through

    Right now the arm drops the moment the sensor stops seeing the car. A real car would still be under it. Keep the arm up until the car has been gone for 3 seconds.

    Adds: Nothing new. Starts from: Make it a gate (step 4).

    Pieces you can use

    unsigned long lastSeen = 0;   // above setup()

if (car) {
  lastSeen = millis();        // millis() counts ms since the board started
}
if (millis() - lastSeen >= 3000) {
  // 3 seconds with no car
}
    Hint 1

    Why not delay(3000)? While it waits, the sensor stops reading, so a second car would not be seen.

    Hint 2

    Add a bool isOpen that remembers whether the arm is up, so you only open and close when it changes.

    // Parking gate, hold-the-arm challenge answer. RCC ACM Arduino lab, 2026-10-29.
// The sensor sees a car. The servo is the gate arm.
// The arm stays up until the car has been gone for 3 seconds.

#include <Servo.h>

const int TRIG = 12;       // sensor Trig
const int ECHO = 11;       // sensor Echo
const int RED = 4;         // red light
const int GREEN = 5;       // green light
const int SERVO_PIN = 9;   // servo orange wire

const int ARM_DOWN = 0;    // arm angle when the gate is closed
const int ARM_UP = 90;     // arm angle when the gate is open
const int CAR_CM = 10;     // anything closer than this many cm is a car

Servo gate;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  gate.attach(SERVO_PIN);
  gate.write(ARM_DOWN);
}

// Gets the distance to the nearest thing in front of the sensor, in cm.
// Gives back 0 when no echo comes back.
long readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);                  // a 10 microsecond pulse starts a reading
  digitalWrite(TRIG, LOW);
  long us = pulseIn(ECHO, HIGH, 30000);   // wait at most 30 ms for the echo
  return us / 58;                         // 58 microseconds per cm
}
const unsigned long HOLD_MS = 3000;   // how long the arm stays up after the car leaves
unsigned long lastSeen = 0;           // millis() the last time a car was seen
bool isOpen = false;                  // is the arm up right now?

void openGate() {
  digitalWrite(GREEN, HIGH);
  digitalWrite(RED, LOW);
  gate.write(ARM_UP);
  isOpen = true;
}

void closeGate() {
  digitalWrite(RED, HIGH);
  digitalWrite(GREEN, LOW);
  gate.write(ARM_DOWN);
  isOpen = false;
}

void loop() {
  long cm = readCm();
  bool car = (cm > 0 && cm < CAR_CM);

  Serial.print("cm: ");
  Serial.println(cm);

  if (car) {
    lastSeen = millis();          // millis() = ms since the board started
    if (!isOpen) {
      openGate();
    }
  } else if (isOpen && millis() - lastSeen >= HOLD_MS) {
    closeGate();
  } else if (!isOpen) {
    closeGate();                  // keeps the red light on at the start
  }

  delay(60);
}

// Open the Serial Monitor at 9600 baud and press each key. It prints the key and where it was found.
// Press 1, then 2. 1 must print "1 (row 1, column 1)" and 2 must print "2 (row 1, column 2)".
// If not, see the fixes in the comment just below.

// ---- Keypad: no library needed ----
// The keypad's 8 pins: 1 to 4 are the rows, 5 to 8 are the columns (keys face up, ribbon toward you,
// pins counted from the left). Check with keypad_test: press 1, then 2.
//   1 prints D: use ROW_PINS {A4, A3, A2, A1} and COL_PINS {10, 8, 6, 3}, upload, and test again.
//   2 prints 4: swap the two lists.
const byte ROW_PINS[4] = {3, 6, 8, 10};      // keypad pins 1, 2, 3, 4
const byte COL_PINS[4] = {A1, A2, A3, A4};   // keypad pins 5, 6, 7, 8
const char KEYS[4][4] = {
  {'1', '2', '3', 'A'},
  {'4', '5', '6', 'B'},
  {'7', '8', '9', 'C'},
  {'*', '0', '#', 'D'}
};

void keypadSetup() {
  for (int r = 0; r < 4; r++) pinMode(ROW_PINS[r], INPUT);          // rows rest unplugged
  for (int c = 0; c < 4; c++) pinMode(COL_PINS[c], INPUT_PULLUP);   // columns read HIGH until a key joins them to a row
}

// Gives back the key being pressed, or 0 if none. Waits until you let go, so one press is one key.
char scanKey() {
  for (int r = 0; r < 4; r++) {
    pinMode(ROW_PINS[r], OUTPUT);            // one row at a time goes LOW
    digitalWrite(ROW_PINS[r], LOW);
    for (int c = 0; c < 4; c++) {
      if (digitalRead(COL_PINS[c]) == LOW) {             // a key in this row and column is down
        delay(20);                                       // wait out the bounce
        if (digitalRead(COL_PINS[c]) == LOW) {
          while (digitalRead(COL_PINS[c]) == LOW) delay(5);   // wait for the key to come back up
          pinMode(ROW_PINS[r], INPUT);
          return KEYS[r][c];
        }
      }
    }
    pinMode(ROW_PINS[r], INPUT);             // back to resting before the next row
  }
  return 0;
}

void setup() {
  Serial.begin(9600);
  keypadSetup();
  Serial.println("Press a key");
}

void loop() {
  char key = scanKey();
  if (key != 0) {
    for (int r = 0; r < 4; r++)
      for (int c = 0; c < 4; c++)
        if (KEYS[r][c] == key) {
          Serial.print(key);
          Serial.print(" (row ");
          Serial.print(r + 1);
          Serial.print(", column ");
          Serial.print(c + 1);
          Serial.println(")");
        }
  }
}

    Harder: lock out after 3 wrong codes

    After 3 wrong codes in a row, ignore the keypad for 10 seconds and blink red. Show one * in the Serial Monitor for each key instead of the digit.

    secret_stretch.ino

    // Secret code gate, harder version. RCC ACM parking gate, 2026-10-29.
// Same as the answer, plus: 3 wrong codes in a row lock the keypad for 10 seconds,
// and the Serial Monitor shows one * for each key typed instead of the digits.

#include <Servo.h>

const int TRIG = 12;       // sensor Trig
const int ECHO = 11;       // sensor Echo
const int RED = 4;         // red light
const int GREEN = 5;       // green light
const int SERVO_PIN = 9;   // servo orange wire

const int ARM_DOWN = 0;    // arm angle when the gate is closed
const int ARM_UP = 90;     // arm angle when the gate is open
const int CAR_CM = 10;     // anything closer than this many cm is a car

Servo gate;

const String SECRET = "1234";   // change it to your own code
String typed = "";
bool unlocked = false;
unsigned long lastSeen = 0;     // millis() when the sensor last saw the car
int wrongTries = 0;
bool locked = false;            // true for 10 s after 3 wrong codes
unsigned long lockStart = 0;    // millis() when the lockout started

// ---- Keypad: no library needed ----
// The keypad's 8 pins: 1 to 4 are the rows, 5 to 8 are the columns (keys face up, ribbon toward you,
// pins counted from the left). Check with keypad_test: press 1, then 2.
//   1 prints D: use ROW_PINS {A4, A3, A2, A1} and COL_PINS {10, 8, 6, 3}, upload, and test again.
//   2 prints 4: swap the two lists.
const byte ROW_PINS[4] = {3, 6, 8, 10};      // keypad pins 1, 2, 3, 4
const byte COL_PINS[4] = {A1, A2, A3, A4};   // keypad pins 5, 6, 7, 8
const char KEYS[4][4] = {
  {'1', '2', '3', 'A'},
  {'4', '5', '6', 'B'},
  {'7', '8', '9', 'C'},
  {'*', '0', '#', 'D'}
};

void keypadSetup() {
  for (int r = 0; r < 4; r++) pinMode(ROW_PINS[r], INPUT);          // rows rest unplugged
  for (int c = 0; c < 4; c++) pinMode(COL_PINS[c], INPUT_PULLUP);   // columns read HIGH until a key joins them to a row
}

// Gives back the key being pressed, or 0 if none. Waits until you let go, so one press is one key.
char scanKey() {
  for (int r = 0; r < 4; r++) {
    pinMode(ROW_PINS[r], OUTPUT);            // one row at a time goes LOW
    digitalWrite(ROW_PINS[r], LOW);
    for (int c = 0; c < 4; c++) {
      if (digitalRead(COL_PINS[c]) == LOW) {             // a key in this row and column is down
        delay(20);                                       // wait out the bounce
        if (digitalRead(COL_PINS[c]) == LOW) {
          while (digitalRead(COL_PINS[c]) == LOW) delay(5);   // wait for the key to come back up
          pinMode(ROW_PINS[r], INPUT);
          return KEYS[r][c];
        }
      }
    }
    pinMode(ROW_PINS[r], INPUT);             // back to resting before the next row
  }
  return 0;
}

// Gets the distance to the nearest thing in front of the sensor, in cm.
// Gives back 0 when no echo comes back.
long readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);                  // a 10 microsecond pulse starts a reading
  digitalWrite(TRIG, LOW);
  long us = pulseIn(ECHO, HIGH, 30000);   // wait at most 30 ms for the echo
  return us / 58;                         // 58 microseconds per cm
}

// Blinks the red light 3 times: wrong code.
void blinkRed() {
  for (int i = 0; i < 3; i++) {
    digitalWrite(RED, LOW);
    delay(150);
    digitalWrite(RED, HIGH);
    delay(150);
  }
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  gate.attach(SERVO_PIN);
  gate.write(ARM_DOWN);
  keypadSetup();
}

void loop() {
  long cm = readCm();
  bool car = (cm > 0 && cm < CAR_CM);
  if (car) lastSeen = millis();
  bool carHere = millis() - lastSeen < 1000;   // one missed reading doesn't count as the car leaving
  char key = scanKey();
  if (locked && millis() - lockStart >= 10000) locked = false;   // subtracting stays right when millis() wraps
  bool lockedOut = locked;

  if (lockedOut) {
    key = 0;                      // ignore the keypad while locked out
  }

  if (key == '*') {
    typed = "";
    Serial.println();
  } else if (key == '#') {
    Serial.println();
    if (typed == SECRET) {
      unlocked = true;
      wrongTries = 0;
      Serial.println("Code OK");
    } else {
      wrongTries++;
      Serial.println("Wrong code");
      blinkRed();
      if (wrongTries >= 3) {
        locked = true;
        lockStart = millis();
        wrongTries = 0;
        Serial.println("Locked for 10 seconds");
      }
    }
    typed = "";
  } else if (key != 0 && typed.length() < 8) {
    typed += key;                 // at most 8 keys
    Serial.print('*');            // show a * for each key, never the key itself
  }

  if (carHere && unlocked) {
    digitalWrite(GREEN, HIGH);
    digitalWrite(RED, LOW);
    gate.write(ARM_UP);
  } else {
    bool blinkOn = (millis() / 250) % 2 == 0;
    digitalWrite(RED, lockedOut ? (blinkOn ? HIGH : LOW) : HIGH);   // red blinks while locked out
    digitalWrite(GREEN, LOW);
    gate.write(ARM_DOWN);
  }

  if (!carHere) {
    unlocked = false;
  }

  delay(60);
}

    gate_stretch.ino

    // Parking gate, smooth-arm challenge answer. RCC ACM Arduino lab, 2026-10-29.
// The arm moves 1 degree at a time with no delay(), so the sensor keeps
// reading while it moves. If a car shows up while the arm is coming down,
// the arm goes back up. Keeps the spot count and full-lot light from the lot-full challenge.
//
// The gate is always in one of 4 states:
//   CLOSED  -> a car shows up and there's a spot -> OPENING
//   OPENING -> arm reaches ARM_UP                 -> OPEN
//   OPEN    -> no car for HOLD_MS                 -> CLOSING
//   CLOSING -> arm reaches ARM_DOWN               -> CLOSED
//   CLOSING -> a car shows up                     -> OPENING (no new count)

#include <Servo.h>

const int TRIG = 12;
const int ECHO = 11;
const int RED = 4;
const int GREEN = 5;
const int SERVO_PIN = 9;
const int EXIT_BUTTON = 2;

const int ARM_DOWN = 0;
const int ARM_UP = 90;
const int CAR_CM = 10;

const int SPOTS = 5;
const unsigned long HOLD_MS = 3000;
const unsigned long STEP_MS = 15;     // one degree every 15 ms, like Sweep
const unsigned long SENSOR_MS = 60;   // one reading every 60 ms (datasheet)
const unsigned long BLINK_MS = 250;

enum GateState { CLOSED, OPENING, OPEN, CLOSING };
GateState state = CLOSED;

Servo gate;
int angle = ARM_DOWN;
int spotsLeft = SPOTS;
bool car = false;
unsigned long lastSeen = 0;
unsigned long lastStep = 0;
unsigned long lastRead = 0;
int lastButton = HIGH;
unsigned long lastChange = 0;  // millis() of the last time the button reading changed, so one bouncy press counts once

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(EXIT_BUTTON, INPUT_PULLUP);
  gate.attach(SERVO_PIN);
  gate.write(angle);
}

long readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long us = pulseIn(ECHO, HIGH, 30000);
  return us / 58;
}

void printState() {
  const char* names[] = { "CLOSED", "OPENING", "OPEN", "CLOSING" };
  Serial.print(names[state]);
  Serial.print("   spots left: ");
  Serial.println(spotsLeft);
}

void setState(GateState next) {
  state = next;
  printState();
}

void loop() {
  unsigned long now = millis();

  // 1. Read the sensor every SENSOR_MS.
  if (now - lastRead >= SENSOR_MS) {
    lastRead = now;
    long cm = readCm();
    car = (cm > 0 && cm < CAR_CM);
    if (car) {
      lastSeen = millis();
    }
  }

  // 2. Exit button: one car out per press.
  int button = digitalRead(EXIT_BUTTON);
  if (button != lastButton) {
    if (button == LOW && millis() - lastChange > 50) {
      if (spotsLeft < SPOTS) {
        spotsLeft = spotsLeft + 1;
      }
      printState();
    }
    lastChange = millis();
  }
  lastButton = button;

  // 3. Decide the next state.
  switch (state) {
    case CLOSED:
      if (car && spotsLeft > 0) {
        spotsLeft = spotsLeft - 1;
        setState(OPENING);
      }
      break;
    case OPENING:
      if (angle >= ARM_UP) {
        setState(OPEN);
      }
      break;
    case OPEN:
      if (!car && millis() - lastSeen >= HOLD_MS) {
        setState(CLOSING);
      }
      break;
    case CLOSING:
      if (car) {
        setState(OPENING);          // same car or a new one: don't drop the arm on it
      } else if (angle <= ARM_DOWN) {
        setState(CLOSED);
      }
      break;
  }

  // 4. Move the arm 1 degree per STEP_MS. The while catches up if
  //    pulseIn() held up the loop for a few ms.
  while (millis() - lastStep >= STEP_MS) {
    lastStep += STEP_MS;
    if (state == OPENING && angle < ARM_UP) {
      angle = angle + 1;
    } else if (state == CLOSING && angle > ARM_DOWN) {
      angle = angle - 1;
    }
  }
  gate.write(angle);

  // 5. Lights: green only when fully open. Red blinks when full and closed.
  digitalWrite(GREEN, state == OPEN ? HIGH : LOW);
  if (state == OPEN) {
    digitalWrite(RED, LOW);
  } else if (state == CLOSED && spotsLeft == 0) {
    digitalWrite(RED, (millis() / BLINK_MS) % 2 == 0 ? HIGH : LOW);
  } else {
    digitalWrite(RED, HIGH);
  }
}

FixesStuck?

The Serial Monitor always says cm: 0

Trig goes from row 21 to pin 12 and Echo from row 22 to pin ~11. If those two are swapped, it reads 0. Also check e20 goes to the + rail and e23 to the - rail.

The Serial Monitor shows junk characters

Set the box at the bottom right of the Serial Monitor to 9600 baud.

A light never comes on

The long leg goes in row 5 (red) or row 8 (green), and its resistor runs from a6 or a9 into the top - rail. Turned around, an LED stays dark. Also check the GND by pin 13 jumper.

The arm shakes, or the board restarts when the arm moves

Hold the notebook closer so the reading stays under 10 cm. If the board keeps restarting, ask an officer.

Verify says redefinition of 'void setup()'

The starter went in below the blank sketch. Select everything in the window and paste the starter again, over it.

Upload fails

Tools, then Board: pick Arduino UNO (or Arduino UNO R4 WiFi). Tools, then Port: pick the one with your board's name. Close the Serial Monitor and try again.

The keypad gives the wrong keys

Run keypad_test and press 1, then 2. If 1 prints D, change the lists to ROW_PINS[4] = {A4, A3, A2, A1} and COL_PINS[4] = {10, 8, 6, 3}, upload, and test again. If 2 prints 4, swap the two lists. Make the same change in the secret code sketch. If nothing prints at all, check the 8 jumpers against the table.

The button does nothing

Jumpers go in j13 and a11, on opposite corners of the button, and setup() needs pinMode(2, INPUT_PULLUP);.

Before you goPack up

  1. Unplug the USB cable.

  2. Every part and wire goes back in the kit box, the keypad too if you used it.

  3. Put the power module back on the breadboard at the row 1 end, with its + pins on the red lines.

  4. The servo arm stays on the servo.

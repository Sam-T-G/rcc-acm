What you build

A gate like the arm at a parking garage. The ultrasonic sensor sends out a sound too high to hear and times the echo, so it knows how far away the car is. A notebook plays the car. When the car is close, the servo lifts the arm and the light goes from red to green. When it leaves, the arm comes down and the light goes back to red.

Set up

Parts

  • UNO board and its USB cable
  • Breadboard (power module off)
  • Ultrasonic sensor (the blue board with two round eyes)
  • Servo with its arm on
  • 1 red LED and 1 green LED
  • 2 resistors marked 220 ohm (red, red, black, black, brown)
  • 14 jumper wires with a pin on both ends
  • A notebook to play the car

Before you wire

  • Keep the USB cable unplugged while you change wires.
  • If the power module is on the breadboard, pull it off. Today the UNO powers the board.
  • Read the sensor's labels before it goes in. Vcc and Gnd swapped can damage it.

Turn the breadboard so row 1 is on your right and the letters read the right way up. Line a is now the far edge. Put the UNO in front. e21 means line e, row 21.

Four steps

Each step starts from its own starter code. Paste it into a new sketch (File, New Sketch), fill in the part that says your code, and upload. Try the hints before you open an answer.

  1. Step 1 of 4

    Read the sensor

    Goal: Print the distance to whatever is in front of the sensor.

    You should see: Open the Serial Monitor (Tools, then Serial Monitor) and set it to 9600 baud. Hold a notebook flat about 10 cm in front of the sensor. You see cm: 10, and the number drops as the notebook comes closer.

    Starter: paste into a new sketch
    // Stage 1: read the sensor. RCC ACM parking gate, 2026-10-29.
// Goal: print the distance in cm to the Serial Monitor.

const int TRIG = 12;   // sensor Trig
const int ECHO = 11;   // sensor Echo

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  // 1. Send a 10 microsecond HIGH pulse on TRIG.
  //    (digitalWrite LOW, wait 2 us, HIGH, wait 10 us, LOW)

  // 2. Time the echo:  long us = pulseIn(ECHO, HIGH, 30000);

  // 3. Turn it into cm (58 microseconds per cm) and print it.

  delay(60);   // the sensor needs 60 ms between readings
}
    Hint 1

    The sensor starts a reading when Trig goes HIGH for 10 microseconds. delayMicroseconds(10) waits that long.

    Hint 2

    pulseIn(ECHO, HIGH, 30000) gives back how many microseconds the echo took. Divide by 58 to get cm. It gives back 0 when nothing answers within 30 ms.

    // Stage 1 answer: read the sensor and print cm. RCC ACM parking gate, 2026-10-29.

const int TRIG = 12;   // sensor Trig
const int ECHO = 11;   // sensor Echo

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);                  // a 10 microsecond pulse starts a reading
  digitalWrite(TRIG, LOW);

  long us = pulseIn(ECHO, HIGH, 30000);   // wait at most 30 ms; 0 means no echo
  long cm = us / 58;                      // 58 microseconds per cm

  Serial.print("cm: ");
  Serial.println(cm);

  delay(60);
}

  1. Challenge 1

    Hold the arm until the car is through

    Goal: Right now the arm drops the moment the sensor stops seeing the car. A real car would still be under it. Keep the arm up until the car has been gone for 3 seconds.

    Adds: Nothing new. Starts from: Make it a gate (step 4).

    Pieces you can use:

    unsigned long lastSeen = 0;   // above setup()

if (car) {
  lastSeen = millis();        // millis() counts ms since the board started
}
if (millis() - lastSeen >= 3000) {
  // 3 seconds with no car
}
    Hint 1

    Why not delay(3000)? While it waits, the sensor stops reading, so a second car would not be seen.

    Hint 2

    Add a bool isOpen that remembers whether the arm is up, so you only open and close when it changes.

    // Parking gate, count-the-spots challenge answer. RCC ACM Arduino lab, 2026-10-29.
// Counts open spots. Each time the gate opens, one car came in.
// Each press of the exit button is one car going out.

#include <Servo.h>

const int TRIG = 12;       // sensor Trig
const int ECHO = 11;       // sensor Echo
const int RED = 4;         // red light
const int GREEN = 5;       // green light
const int SERVO_PIN = 9;   // servo orange wire
const int EXIT_BUTTON = 2; // exit button: one leg row to pin 2, the other to the - rail

const int ARM_DOWN = 0;    // arm angle when the gate is closed
const int ARM_UP = 90;     // arm angle when the gate is open
const int CAR_CM = 10;     // anything closer than this many cm is a car

const int SPOTS = 5;                  // spots in the lot
const unsigned long HOLD_MS = 3000;   // how long the arm stays up after the car leaves

Servo gate;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(EXIT_BUTTON, INPUT_PULLUP);   // reads HIGH until pressed
  gate.attach(SERVO_PIN);
  gate.write(ARM_DOWN);
}

// Gets the distance to the nearest thing in front of the sensor, in cm.
// Gives back 0 when no echo comes back.
long readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);                  // a 10 microsecond pulse starts a reading
  digitalWrite(TRIG, LOW);
  long us = pulseIn(ECHO, HIGH, 30000);   // wait at most 30 ms for the echo
  return us / 58;                         // 58 microseconds per cm
}

int spotsLeft = SPOTS;
unsigned long lastSeen = 0;   // millis() the last time a car was seen
bool isOpen = false;          // is the arm up right now?
int lastButton = HIGH;        // the button's reading last time through loop()

void openGate() {
  digitalWrite(GREEN, HIGH);
  digitalWrite(RED, LOW);
  gate.write(ARM_UP);
  isOpen = true;
}

void closeGate() {
  digitalWrite(RED, HIGH);
  digitalWrite(GREEN, LOW);
  gate.write(ARM_DOWN);
  isOpen = false;
}

void printSpots() {
  Serial.print("Spots left: ");
  Serial.println(spotsLeft);
}

void loop() {
  long cm = readCm();
  bool car = (cm > 0 && cm < CAR_CM);

  // Car in: count once, when the gate goes from closed to open.
  if (car) {
    lastSeen = millis();
    if (!isOpen) {
      openGate();
      spotsLeft = spotsLeft - 1;
      printSpots();
    }
  } else if (isOpen && millis() - lastSeen >= HOLD_MS) {
    closeGate();
  } else if (!isOpen) {
    closeGate();
  }

  // Car out: count once per press, when the reading goes from HIGH to LOW.
  int button = digitalRead(EXIT_BUTTON);
  if (button == LOW && lastButton == HIGH) {
    if (spotsLeft < SPOTS) {
      spotsLeft = spotsLeft + 1;
    }
    printSpots();
  }
  lastButton = button;

  delay(60);
}

    // Parking gate, lot-full challenge answer. RCC ACM Arduino lab, 2026-10-29.
// Full lot: at 0 spots the gate stays down and the red light blinks.

#include <Servo.h>

const int TRIG = 12;       // sensor Trig
const int ECHO = 11;       // sensor Echo
const int RED = 4;         // red light
const int GREEN = 5;       // green light
const int SERVO_PIN = 9;   // servo orange wire
const int EXIT_BUTTON = 2; // exit button: one leg row to pin 2, the other to the - rail

const int ARM_DOWN = 0;    // arm angle when the gate is closed
const int ARM_UP = 90;     // arm angle when the gate is open
const int CAR_CM = 10;     // anything closer than this many cm is a car

const int SPOTS = 5;                  // spots in the lot
const unsigned long HOLD_MS = 3000;   // how long the arm stays up after the car leaves

Servo gate;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(EXIT_BUTTON, INPUT_PULLUP);   // reads HIGH until pressed
  gate.attach(SERVO_PIN);
  gate.write(ARM_DOWN);
}

// Gets the distance to the nearest thing in front of the sensor, in cm.
// Gives back 0 when no echo comes back.
long readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);                  // a 10 microsecond pulse starts a reading
  digitalWrite(TRIG, LOW);
  long us = pulseIn(ECHO, HIGH, 30000);   // wait at most 30 ms for the echo
  return us / 58;                         // 58 microseconds per cm
}

const unsigned long BLINK_MS = 250;   // red light blink speed when the lot is full

int spotsLeft = SPOTS;
unsigned long lastSeen = 0;
bool isOpen = false;
int lastButton = HIGH;

void openGate() {
  digitalWrite(GREEN, HIGH);
  digitalWrite(RED, LOW);
  gate.write(ARM_UP);
  isOpen = true;
}

void closeGate() {
  digitalWrite(GREEN, LOW);
  gate.write(ARM_DOWN);
  isOpen = false;
}

void printSpots() {
  Serial.print("Spots left: ");
  Serial.println(spotsLeft);
}

void loop() {
  long cm = readCm();
  bool car = (cm > 0 && cm < CAR_CM);
  bool full = (spotsLeft == 0);

  if (car && (isOpen || !full)) {
    lastSeen = millis();
    if (!isOpen) {
      openGate();
      spotsLeft = spotsLeft - 1;
      printSpots();
    }
  } else if (isOpen && millis() - lastSeen >= HOLD_MS) {
    closeGate();
  }

  // Red light: off while open, blinking when full, on otherwise.
  if (!isOpen) {
    if (full) {
      bool blinkOn = (millis() / BLINK_MS) % 2 == 0;
      digitalWrite(RED, blinkOn ? HIGH : LOW);
    } else {
      digitalWrite(RED, HIGH);
    }
  }

  int button = digitalRead(EXIT_BUTTON);
  if (button == LOW && lastButton == HIGH) {
    if (spotsLeft < SPOTS) {
      spotsLeft = spotsLeft + 1;
    }
    printSpots();
  }
  lastButton = button;

  delay(60);
}

    Harder: an arm that will not close on a car

    Goal: Move the arm 1 degree every 15 ms with no delay(), so the sensor keeps reading while the arm moves. If a car shows up while the arm is coming down, the arm goes back up. Keep the spot count and the full-lot light.

    Adds: Nothing new. Starts from: Lot full.

    Pieces you can use:

switch (state) {
  case CLOSING:
    if (car) state = OPENING;   // a car under the arm: back up

  // ...

    Hint 1

    Hint 2

    Keep the arm angle in a variable and change it by 1 each time 15 ms have passed, using millis() like the hold challenge.

    Show an answer
    One answer
    // Parking gate, smooth-arm challenge answer. RCC ACM Arduino lab, 2026-10-29.
// The arm moves 1 degree at a time with no delay(), so the sensor keeps
// reading while it moves. If a car shows up while the arm is coming down,
// the arm goes back up. Keeps the spot count and full-lot light from the lot-full challenge.
//
// The gate is always in one of 4 states:
//   CLOSED  -> a car shows up and there's a spot -> OPENING
//   OPENING -> arm reaches ARM_UP                 -> OPEN
//   OPEN    -> no car for HOLD_MS                 -> CLOSING
//   CLOSING -> arm reaches ARM_DOWN               -> CLOSED
//   CLOSING -> a car shows up                     -> OPENING (no new count)

#include <Servo.h>

const int TRIG = 12;
const int ECHO = 11;
const int RED = 4;
const int GREEN = 5;
const int SERVO_PIN = 9;
const int EXIT_BUTTON = 2;

const int ARM_DOWN = 0;
const int ARM_UP = 90;
const int CAR_CM = 10;

const int SPOTS = 5;
const unsigned long HOLD_MS = 3000;
const unsigned long STEP_MS = 15;     // one degree every 15 ms, like Sweep
const unsigned long SENSOR_MS = 60;   // one reading every 60 ms (datasheet)
const unsigned long BLINK_MS = 250;

enum GateState { CLOSED, OPENING, OPEN, CLOSING };
GateState state = CLOSED;

Servo gate;
int angle = ARM_DOWN;
int spotsLeft = SPOTS;
bool car = false;
unsigned long lastSeen = 0;
unsigned long lastStep = 0;
unsigned long lastRead = 0;
int lastButton = HIGH;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(EXIT_BUTTON, INPUT_PULLUP);
  gate.attach(SERVO_PIN);
  gate.write(angle);
}

long readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long us = pulseIn(ECHO, HIGH, 30000);
  return us / 58;
}

void printState() {
  const char* names[] = { "CLOSED", "OPENING", "OPEN", "CLOSING" };
  Serial.print(names[state]);
  Serial.print("   spots left: ");
  Serial.println(spotsLeft);
}

void setState(GateState next) {
  state = next;
  printState();
}

void loop() {
  unsigned long now = millis();

  // 1. Read the sensor every SENSOR_MS.
  if (now - lastRead >= SENSOR_MS) {
    lastRead = now;
    long cm = readCm();
    car = (cm > 0 && cm < CAR_CM);
    if (car) {
      lastSeen = millis();
    }
  }

  // 2. Exit button: one car out per press.
  int button = digitalRead(EXIT_BUTTON);
  if (button == LOW && lastButton == HIGH) {
    if (spotsLeft < SPOTS) {
      spotsLeft = spotsLeft + 1;
    }
    printState();
  }
  lastButton = button;

  // 3. Decide the next state.
  switch (state) {
    case CLOSED:
      if (car && spotsLeft > 0) {
        spotsLeft = spotsLeft - 1;
        setState(OPENING);
      }
      break;
    case OPENING:
      if (angle >= ARM_UP) {
        setState(OPEN);
      }
      break;
    case OPEN:
      if (!car && millis() - lastSeen >= HOLD_MS) {
        setState(CLOSING);
      }
      break;
    case CLOSING:
      if (car) {
        setState(OPENING);          // same car or a new one: don't drop the arm on it
      } else if (angle <= ARM_DOWN) {
        setState(CLOSED);
      }
      break;
  }

  // 4. Move the arm 1 degree per STEP_MS. The while catches up if
  //    pulseIn() held up the loop for a few ms.
  while (millis() - lastStep >= STEP_MS) {
    lastStep += STEP_MS;
    if (state == OPENING && angle < ARM_UP) {
      angle = angle + 1;
    } else if (state == CLOSING && angle > ARM_DOWN) {
      angle = angle - 1;
    }
  }
  gate.write(angle);

  // 5. Lights: green only when fully open. Red blinks when full and closed.
  digitalWrite(GREEN, state == OPEN ? HIGH : LOW);
  if (state == OPEN) {
    digitalWrite(RED, LOW);
  } else if (state == CLOSED && spotsLeft == 0) {
    digitalWrite(RED, (millis() / BLINK_MS) % 2 == 0 ? HIGH : LOW);
  } else {
    digitalWrite(RED, HIGH);
  }
}

Stuck?

The Serial Monitor always says cm: 0

Trig goes from row 21 to pin 12 and Echo from row 22 to pin ~11. Swapped, it reads 0. Also check e20 goes to the + rail and e23 to the - rail.

The Serial Monitor shows junk characters

Set the box at the bottom right of the Serial Monitor to 9600 baud.

A light never comes on

The long leg goes in row 5 (red) or row 8 (green), and its resistor runs from a6 or a9 into the top - rail. Turned around, an LED stays dark. Also check the GND by pin 13 jumper.

The arm shakes, or the board restarts when the arm moves

Hold the notebook closer so the reading stays under the line. If the board keeps restarting, ask an officer.

Upload fails

Tools, then Board: pick Arduino UNO. Tools, then Port: pick the one that says Arduino UNO. Close the Serial Monitor and try again.

The button does nothing

Jumpers go in j13 and a11, on opposite corners of the button, and setup() needs pinMode(2, INPUT_PULLUP);.
